# MoonInAI 全站视觉重构提案

状态：用户已确认，已在当前 main 工作区完成实施。

## 方向比较

1. 月面实验室（推荐）：深黑、银白、电光绿；巨大品牌字与真实月面质感构成首屏。品牌辨识度强，适合 AI 顾问与公开构建者身份，需要控制大图和动画性能。
2. 瑞士科技海报：冷白、黑字、钴蓝；大字号、严格网格、作品图主导。内容阅读更轻松，科幻氛围较弱。
3. 创作者数字工作室：石墨灰、暖白、橙色；人物照片、作品与编辑式排版。个人亲近感强，但与当前暖色方向差异较小。

## 推荐方案：月面实验室

视觉主张：用深空的留白、月面的实体质感和清晰的现代排版，呈现一个正在把 AI 带进真实业务的个人工作室。

色彩：背景 #080A0B，次级表面 #121619，正文 #F1F3EF，辅助文字 #A5ADA8，强调色 #C6FF69。强调色用于主要按钮、链接状态和小范围视觉提示。正式实现中检查实际组合对比度。

字体：统一现代无衬线系统，中文优先系统黑体，英文使用紧凑的大字号品牌排版；等宽系统字体仅用于编号和项目元信息。移除当前四套远程字体的混用。

## 首屏构图

全宽深色画布，上方简洁导航：MoonInAI / 作品 / 服务 / 关于 / 联系。

MoonInAI 是第一视觉层级，采用大字标。主文案为「让 AI，进入真实业务。」；辅助文案为「企业 AI 系统 · 智能体与工作流 · 公开构建」。主要按钮「聊聊你的项目」，次要入口「查看我的作品」。

一颗局部裁切、带清晰月面纹理的巨大月球放在右侧，与整个背景相连；左侧文字区域保持安静。底部以细线和小字提示继续浏览。去掉首屏随机 SIGNAL、LATENCY 等读数。

## 页面顺序

1. 品牌首屏：明确是谁、做什么、如何联系。
2. 作品与开源：将现有 Proof of Work 和 Current Build 的有效内容组织成大幅作品展示及项目列表；使用真实项目资料，不虚构客户、成果或实时数据。
3. 服务：五个编号横向条目，分别展示传统企业 AI 系统、工作流/智能体定制、新手课程、副业陪跑和线下沙龙。每条写清对象、交付和入口；避免全部做成同等权重的卡片。
4. 方法：目标诊断 → 流程设计 → 搭建交付 → 陪跑迭代。用连贯步骤代替雷达装饰。
5. 关于：大幅真实人物照片、简洁个人介绍及现有背书；照片不再叠加工程图注。
6. 联系：醒目标题「从一个真实问题开始。」与现有微信二维码、社交入口；移动端可直接查看二维码。

## 动效

- 首屏品牌、文案、按钮依次入场，总时长约 800ms。
- 桌面月面随滚动轻微位移，作品进入视口时渐显；不劫持滚动。
- 服务条目 hover/focus 时改变文字与箭头位置，保持明确点击反馈。
- prefers-reduced-motion 下关闭非必要动画；移动端取消视差；内容不依赖动画或 JavaScript 才能阅读。

直接在当前项目工作，不创建隔离工作树。已有未跟踪预览和计划文件保留。

- 运行项目现有测试；涉及旧视觉结构的断言按新结构更新，保留功能性校验。
