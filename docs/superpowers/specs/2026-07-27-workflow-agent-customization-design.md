# AI 工作流 / 智能体定制服务改造设计

## 目标

将网站原「企业 AI 培训」服务全面改为「AI 工作流 / 智能体定制」，聚焦广东企业的业务流程自动化、知识与工具接入、智能体配置、测试与持续优化。

## URL 与索引策略

- 保留既有 URL：`/guangdong-ai-training.html`。
- 该页 canonical 继续使用 `https://mooninai.top/guangdong-ai-training.html`，避免已存在的内部链接、外部链接或已发现 URL 失效。
- sitemap 继续保留该 URL，网站总规范 URL 数量维持为 5。
- 不新增近似的工作流/智能体 URL，避免内容重复与静态站无法配置 301 跳转的问题。

## 首页改动

- 服务信号台、服务列表、专题入口、跑马灯及首页 SEO title、description、Open Graph 均用「AI 工作流 / 智能体定制」取代「企业 AI 培训」。
- 首页说明该服务帮助企业将高频任务拆成可执行 AI 工作流，并根据场景定制智能体，而不将其描述为培训服务。

## 服务页改动

`guangdong-ai-training.html` 保持文件名不变，页面内容重写为：

- H1：广东 AI 工作流 / 智能体定制。
- 目标客户：需要处理销售、运营、知识、内容或跨部门协作中高频重复任务的广东企业。
- 服务路径：业务诊断 → 工作流设计 → 知识与工具接入 → 智能体配置 → 真实任务测试 → 迭代优化。
- 交付内容：工作流蓝图、知识与提示词资产、可用智能体配置、操作说明与优化建议。
- CTA：微信咨询；相关服务链接回首页、企业 AI 系统、广东 AI 沙龙和 AI 新手入门课程。
- 不虚构集成平台、交付周期、项目价格、成功率、客户案例或自动化效果。

## 互链与测试

- 其余三条服务页将旧文本链接「企业 AI 培训」更新为「AI 工作流 / 智能体定制」，URL 保持不变。
- 静态测试验证：首页不含旧的主服务名；首页与服务页具有新服务名；该服务页具有唯一 title、description、H1 和原规范 URL；sitemap 仍列原 URL 且总数为 5。
- 本地 HTTP 检查确认原 URL 返回新标题和 H1，sitemap/robots 可访问。

- `npm test` 和 `git diff --check` 通过。
